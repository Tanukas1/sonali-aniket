# sonali-aniket

Digital wedding invitation website built with Next.js, React, and Tailwind CSS.

## Features
- **Interactive Envelope Opening**: Wax seal interaction that plays the high-definition opening video with sound controls.
- **Save the Date & Scratch Card**: Interactive canvas-based scratch-to-reveal hearts (Day, Month, Year) with particle confetti burst animation.
- **Dynamic Countdown Timer**: Real-time live countdown down to the second.
- **Venue & Google Maps Navigation**: Venue details with direct Google Maps route link.
- **Atmospheric Animations**: Falling rose petals, floating gold sparkle stars, and interactive touch-ripple shimmer.
- **Fully Responsive**: Mobile, tablet, and desktop views with responsive container query scaling.

## Getting Started

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the invitation.
